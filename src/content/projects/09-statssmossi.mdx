An internal dashboard that uses browser automation to collect hosting and domain information and keep an operational inventory up to date.

Combines scheduled collection with historical measurements, explicit error states and preservation of the last valid data when a source is unavailable. Authentication challenges can require human intervention.

This project demonstrates browser automation and internal tooling.
