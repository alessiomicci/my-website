A management application for project and construction-site operations, with project records, employee assignments, work phases, time entries, budget monitoring and PDF reporting.

Combines a Filament administration panel with an installable React/Inertia field app for recording hours and receiving push notifications. Role-based access separates administration, project management and employee workflows.

I used AI coding assistance during development, while retaining responsibility for architecture, implementation review and validation. The repository includes automated tests covering authentication, access rules, time entries, the project lifecycle and reporting.

This is a private internal tool, so no live or source-code links are provided.

Automatic budget-threshold alerts are prepared but not active; they depend on defining a reference hourly cost.
