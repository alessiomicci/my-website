End-to-end product architecture, UI/UX design, and full-stack development of a web application and live broadcasting system for an 8-a-side football tournament with custom Kings League-inspired rules.

Designed a unified platform combining a public-facing portal for live standings and match schedules, a Filament-based administrative panel for league staff, and an automated, polling-driven Live TV display interface for pitch-side big screens. Engineered a client-side real-time match timer synchronized with server-side polling, dynamic slideshow rotations for inter-match intervals, and real-time special event overlay triggers (penalties, double goals) delivered without web-socket overhead.
