End-to-end product architecture, UI/UX design, and full-stack development of a web application and live broadcasting system for an 8-a-side football tournament with custom Kings League-inspired rules.

The platform combines a public portal for standings and match schedules, a Filament administration panel for league staff, and an automated Live TV interface for pitch-side displays.

## Live TV updates and match timing

The TV view refreshes server data through Inertia polling every 15 seconds. Between refreshes, a local timer updates the match clock every second using the server-provided start time and elapsed seconds. An optional URL offset adjusts the clock to compensate for display delay.

This separates the clock display from periodic server updates: the timer continues to advance between requests, while scores and special-event overlays update on subsequent polls rather than arriving instantly. When no match is active, the display rotates every 30 seconds through the enabled standings, scorers, fixtures, and tournament-bracket slides, configured per season.
