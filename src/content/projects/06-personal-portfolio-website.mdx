Designed and built this personal portfolio website from scratch, using an AI-driven development workflow with Claude Code to accelerate iteration while keeping full control over architecture and design decisions.

Implemented a fully custom design system with Astro and Tailwind CSS, a content-collection-driven "My Works" system in MDX with optional per-project links (live site, source, app stores), light/dark theming with no flash of the wrong theme on load, and a lightweight dot-grid hero background — all with an explicit focus on avoiding generic "AI-generated" visual clichés (no glow, no glassmorphism, no gratuitous gradients) in favor of a solid, engineering-first aesthetic.
